Privacy policy

Application: dwarf2-t3-backup (Google OAuth client used by the open-source tools rclone and restic).

Who uses it: only the owner of this GitHub account, for their own data. It is not offered to anyone else.

Google user data accessed: the application uses only the drive.file scope. It can see, create, change and delete only the files it creates itself in the owner's Google Drive (encrypted backup files). It cannot read any other files in the Drive.

How the data is used: solely to store and restore the owner's encrypted backups. The data is encrypted on the owner's computer before upload.

Sharing: no data is shared with, sold to, or transferred to any third party. No analytics or advertising.

Storage and deletion: OAuth tokens are stored only on the owner's own computer. Access can be revoked at any time at myaccount.google.com/permissions; the backup files can be deleted from Google Drive by the owner.

Contact: via github.com/DirtyOldDwarf.
